# 压感笔迹与事件采样验收

## 图形入口（主要使用方式）

在仓库根目录启动任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

然后在浏览器打开绘画窗口：

- <http://localhost:8080/ui/>
- 或直接访问 `ui/index.html`（若浏览器允许本地 ES Module）。

图形界面支持：

- 用压感笔拖动画笔，读取真实压力和倾斜；
- 没有压感笔时，用“鼠标模拟压力”滑块设定压力后作画；运笔过程中也可按 `[` / `]` 实时降/升模拟压力，并可调整笔宽、流量、硬度等参数；
- 叠加显示真实笔迹、红色采样点、绿色采样轨迹和蓝色实际盖印中心；
- 在“回归样例”中打开停笔/重复事件、突变压力、手写曲线正常样例和受控断线/超宽坏样例；
- 撤销最近一笔或一次样例载入（按钮或 `Ctrl/⌘+Z`）；
- 导出由当前浮点画布实际合成并编码的 PNG；
- 运行时参数、导出或验收异常会显示在绘画窗口的错误区域。

## 命令行辅助验收

```bash
node test/run-tests.mjs   # 笔刷与验收断言
node test/ui-harness.mjs  # 无浏览器 DOM 桩，检查图形接线与旧重放
# 或
npm test
```

命令行是辅助手段，覆盖：

- 同一连续解析轨迹在 30/60/120/240 Hz 下的弧长盖印和压力响应；
- 原始事件的逐个、定长、不规则和时间窗等价重分块；
- 事件包乱序归约、精确重复事件识别；
- 停笔与突变压力正例，以及受控移位、满压力错误等反例；
- 独立弧长期望盖印位置、独立光栅像素误差；
- 独立路径覆盖、最早断线和最早超宽定位；
- 撤销快照恢复；
- PNG 编码/解码和导出像素核对。

## 参照边界

对同一份原始事件做等价重分块时，结果要求逐位一致。从解析笔划重新采样得到的轨迹是独立真值参照，但只在采样间隔足以分辨急转、压力峰和盖印间距时适用；极稀疏采样会跳过中间压力或几何结构，验收会把它标为适用范围之外，而不会冒充高频逐位真值。
